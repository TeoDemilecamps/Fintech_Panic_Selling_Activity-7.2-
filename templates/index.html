Panic Sale Risk Predictor

When a portfolio drops, some investors sell in a hurry and lock in their losses. This tool estimates how likely a user is to panic sell within the next 3 trading days, so an investing app can step in with the right nudge before the sale happens.

What is being predicted, and why it matters

The prediction

A logistic regression model predicts stays_invested: 1 if the user sells less than 20% of their portfolio value in the 3 trading days after the observation date, 0 if they panic sell. We headline the probability of a panic sale.

Who it is for

Retail investors on an investing app whose portfolio has fallen from its 3-month peak. Panic selling turns paper losses into real ones for the user and creates outflows and churn for the platform.

How the platform uses it

The risk level triggers a proportionate response: nothing for low risk, a calming educational message for moderate risk, and a cooling-off step with adviser support for high risk.

How it works

The model

Logistic regression with standardised inputs, trained on 2,000 synthetic investors (75% train / 25% test, about 76% test accuracy). Higher app checking, a deeper drawdown and a larger share of single stocks or crypto each lower the chance of staying invested.

Risk levels

Low: panic-sale probability under 30%.
Moderate: 30% to 60%.
High: above 60%.

Use it from code

Other apps can call POST /api/predict with a JSON body and get the same prediction back. See the README for an example request.

curl -X POST {{ request.url_root }}api/predict \
  -H "Content-Type: application/json" \
  -d '{"app_checks_per_day": 18, "portfolio_drawdown_pct": 30, "single_stock_crypto_share_pct": 70}'

Educational project. The model is trained on synthetic data and does not use real customer information. It is a demonstration of a machine-learning solution, not financial advice.
